# Trivy Vulnerability Suppression Baseline

## Purpose

Track accepted-risk vulnerabilities discovered by Trivy in CI. When Trivy
reports a HIGH or CRITICAL finding that has no immediate fix, it can be
suppressed here with justification.

## How Trivy suppression works

Trivy uses a `.trivyignore` file (plain text, one CVE per line) at the
repo root. When a finding is added here, Trivy skips it in future runs.

## Rules for adding a suppression

Every suppression requires:
- The CVE ID
- Justification (why we accept this)
- Owner (who reviewed and accepted)
- Review-by date (when to re-evaluate)
